PetAdopt est une application d'adoption d'animaux de compagnie développée avec Flutter pour le frontend et FastAPI pour le backend, en utilisant une architecture microservices. Elle permet aux utilisateurs de créer un compte, de se connecter de manière sécurisée grâce à JWT et bcrypt, de consulter un catalogue de chiens et de chats, de rechercher des animaux, de filtrer les résultats par catégorie, de consulter les détails des animaux et de gérer leurs adoptions, notamment en adoptant ou en annulant une adoption. Le backend est composé de quatre services principaux : un service d'authentification, un service de gestion des animaux, un service de gestion des adoptions et une API Gateway qui centralise les requêtes et vérifie les jetons d'authentification. L'application utilise MongoDB Atlas pour les données d'authentification, PostgreSQL pour le catalogue des animaux et Redis pour la gestion des files d'attente et la communication asynchrone entre les services. Enfin, Docker et Docker Compose facilitent le déploiement et le lancement de l'ensemble des services. Ce projet met en pratique les concepts des microservices, de la communication asynchrone, de la sécurisation des API et du développement d'applications multiplateformes.
